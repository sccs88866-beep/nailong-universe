# 奶龙宇宙 · 三个不太正经的小游戏

奶龙和凑企鹅的三个小游戏，纯静态、零依赖，双击 `index.html` 就能玩，也能直接丢到任意静态托管上给手机打开。键盘和触屏都支持，进度存在本地浏览器。

## 怎么打开

- 直接双击 `index.html`（file:// 也能跑，脚本都是普通 `<script>`）。
- 或者起一个静态服务器：

  ```powershell
  python -m http.server 8080 --bind 0.0.0.0 --directory .
  ```

  电脑上用 <http://127.0.0.1:8080>；同一 Wi-Fi 下的手机用 `http://<电脑内网IP>:8080`（需要防火墙放行，且网络不能开客户端隔离）。

## 玩什么

进入先看序章（可跳过），然后选关：

| 关卡 | 玩法 | 操作 |
|---|---|---|
| 第 1 关 · 接住奶龙 | 凑企鹅的头在底部左右接天上掉下来的奶龙，接到炸弹掉一条命 | 鼠标/手指拖动、← → 或 A/D；空格暂停 |
| 第 2 关 · 敲奶龙 | 3×3 洞里冒出奶龙就敲，混在里面的凑企鹅头别敲。30 秒 | 点击/触摸洞口；空格暂停 |
| 第 3 关 · 奶龙快跑 | 奶龙自动向前跑，跳过滚过来的凑企鹅的头，顺手捡豆子 | 空格 / ↑ / 点击跳跃；空格暂停 |

## 奖励

- **奶龙币**：每局按得分折算，`max(1, round(得分 / 8))`。
- **强化卡**：每局结束三选一，永久生效、可叠加——奶龙磁铁（接住判定 +15%）、幸运豆（得分 +10%）、多一条命、稳如老狗（开局速度 -8%）、起手护盾。
- **商店**：称号三档（80 / 200 / 400 币）+ 两个永久道具（吸铁石 250、备用护盾 320），道具和强化卡叠加。
- 存档在 `localStorage` 的 `beanverse.save.v1`，清掉这条记录就是重开档。

## 目录

```
arcade/
  index.html              页面骨架（大厅 + 序章 + 抽卡弹窗）
  manifest.webmanifest    手机「添加到主屏幕」用
  assets/
    style.css
    app.js                存档、奶龙币、强化卡、商店、路由、音效、覆盖层
    characters/           从两张原图里抠出来的形象
    icons/                主屏图标 192 / 512
  games/
    catch.js  whack.js  jump.js
  tools/
    extract_characters.py 从原图裁三个视图、去白底和棚拍阴影
    make_icons.py         生成主屏图标
    smoke.js              极简 DOM 桩驱动三个游戏的帧循环
    e2e.js                真实浏览器跑一局，验证发币与商店购买
    verify-ui.js          验证序章 → 选关 → 抽卡 → 结算整条流程
    preview.js / mobile.js 截取游戏中和手机视口的画面
  shots/                  预览截图
```

## 自测

```powershell
node tools/smoke.js        # 三个游戏的帧循环 + 暂停/重开/销毁
node tools/verify-ui.js    # 需要 Edge，跑一局验证抽卡与结算
node tools/e2e.js          # 需要 Edge，验证发币与商店购买
```

## 部署

纯静态，没有构建步骤。把 `arcade` 整个目录拖到 Netlify Drop、传到 GitHub Pages 或任意对象存储即可得到一个手机能开、能发给朋友的地址。
